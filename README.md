# finix site

Landing page for finix, built from the doodle-product-site starter (Svelte 5 + Vite), one page.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/ (set SITE_URL for canonical/og/sitemap)
```

Copy lives in `src/components/*.svelte` and `src/lib/content/*`. Colours and the dark theme are in `src/styles/tokens.css`.
